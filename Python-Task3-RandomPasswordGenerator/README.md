# Random Password Generator

This Python program creates a random password using the character types you choose.

## Requirements

- Python 3
- No extra packages are needed. The program uses modules included with Python.

## Run the program

Open a terminal in this folder and run:

```text
python random_passwd_gen.py
```

If your computer uses `python3` to start Python, run:

```text
python3 random_passwd_gen.py
```

## How to use it

1. Choose at least two character types:
   - `u` for uppercase letters
   - `l` for lowercase letters
   - `n` for numbers
   - `s` for symbols
2. Enter the letters for your choices. For example, `uln` uses uppercase
   letters, lowercase letters, and numbers.
3. Enter a password length of at least 8 characters.
4. Choose whether to generate another password with the same settings.

The generated password includes at least one character from every type you
selected. Keep your passwords private.
