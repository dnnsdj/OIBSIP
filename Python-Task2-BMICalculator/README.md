# BMI Calculator

A simple Python program that calculates Body Mass Index (BMI) from a person's
weight and height.

## Requirements

- Python 3

## Run the program

Open a terminal in this folder and run:

```text
python bmi_calc.py
```

Enter your weight in kilograms and your height in metres when asked. The
program displays your BMI rounded to two decimal places and a category:

- Underweight: BMI below 18.5
- Normal: BMI from 18.5 to below 25
- Overweight: BMI from 25 to below 30
- Obese: BMI of 30 or higher

The program asks for numeric values, rejects negative weight, and requires
height to be greater than zero.
